# Flutter Scout verification app

This app is the deterministic simulator fixture used to verify Flutter Scout.
It includes the Supplier smoke workflow, interactive Stress Lab screens, fault
probes, and the runnable public evaluation corpus.

## Public evaluation fixtures

`PublicFixtureScreen` is a bounded parametric renderer for the 60-template ×
five-variant public corpus generated by `evaluation`. An explicitly enabled
debug evaluator selects a strict `public-fixture-v1` configuration through an
authenticated VM-service extension before reset. The app emits completion,
modal, duplicate, and wrong-action events from its own UI/domain callbacks;
Flutter Scout inspect, delta, screenshots, and command claims are never used as
ground truth.

The extension registration is assertion-gated and absent from profile/release
behavior. Opaque completion values and predicate results stay on the protected
evaluator channel and are not rendered or included in the agent task view.

The public fixtures remain non-release evidence: there is no private or frozen
split, no real-app integration, and no claimed simulator episode simply because
the source and deterministic contract tests exist.

Run app checks from this directory with `flutter analyze` and `flutter test`.

## Eye/hand concurrency probe

Stress Lab → Eye-hand probe runs timed work with persistent, transient, or absent
pause requests. The app shows callback timestamps and counts pauses after work
has already finished. It is a deterministic verification fixture, not a
production integration pattern or independent protected benchmark oracle.
See [`agent-session-verification.md`](../../docs/agent-session-verification.md)
for measured results and limits. After navigating to this screen, run the
shipped runtime check from the repository root:

```bash
node tool/agent_runtime_smoke.mjs <named-session> <cli-binary> hold flash quiet
```
